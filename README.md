# TikTok Clean — текущая основа You 4.4 / 46.8.3

Скачать APK: [последний выпуск](https://github.com/topikajo/tiktok-clean/releases/latest). Основа — пользовательский You 4.4 / 46.8.3; это не последняя официальная версия TikTok. Старый профиль 47.1.4 хранится отдельно.

Для Pixel и Poco: [скачать ttc-arm8.apk](https://github.com/topikajo/tiktok-clean/releases/latest/download/ttc-arm8.apk). Файл `ttc-arm64.apk` — та же самая 64-битная сборка под другим привычным названием; скачивать оба не нужно. ARM7/32 пока недоступен: текущая основа не содержит `armeabi-v7a`. В обычных релизах лежат только APK, отчёты вынесены в отдельные технические выпуски.

- При обновлении рекомендаций сразу открывается первый новый ролик. Предыдущий остаётся позади, доступный обратным свайпом. Кнопки возврата нет. Хранится один ролик в оперативной памяти.
- На паузе добавлена кнопка «Кадр»: сохранение видеоповерхности без интерфейса в галерею.
- Сохранены снятие клиентского запрета скачивания и выбор качества из основы You.
- Отключены найденные каналы статистики и сторонних обновлений. Удалены лишние разрешения; найденные системные запросы проходят проверку действия пользователя.
- Удалён отказ исходного мода от новой подписи, который открывал Telegram и завершал приложение. Сертификаты телефона менять не требуется.
- Обновления через публичные GitHub Releases: один небольшой баннер на версию, затем точка во «Входящих» до проверенной загрузки. Кнопка «Скачать» рядом; после загрузки — «Установить». Можно задать HTTPS-зеркало.

Подробности и границы приватности: [PRIVACY-RU.md](PRIVACY-RU.md). Изменения и SHA-256: [release/you-privacy-build.json](release/you-privacy-build.json). Проверки: [release/you-privacy-verification.json](release/you-privacy-verification.json).

## Установка и проверка на телефоне

APK содержит только ARM64. Библиотеки и их размещение проверены для страниц 16 КБ; физические Pixel и Poco не проверялись. На отдельном эмуляторе проверены гостевой запуск, 30 случаев установленного APK, 20 случаев обновления, очередь UI и 100 000 обращений к реальному классу видео. В JVM прошли 45 правил, 100 000 сценариев ленты и 100 000 циклов уведомлений. Реальный аккаунт, живая лента, перехваты исходного мода и экспорт кадра настоящего плеера требуют проверки на телефоне. Эти проверки не измеряют FPS/GPU.

Подпись отличается от официального TikTok и You. Если Android отказывается устанавливать поверх них, предварительно сохраните локальные черновики и удалите прежнее приложение. Предыдущий Clean 47.1.4 имеет более высокий versionCode и также может потребовать удаления. Не удаляйте доверенные сертификаты Android.

В настройках мода переключатель «Сохранять прошлый ролик позади после обновления ленты» включён по умолчанию. Для кадра поставьте видео на паузу и нажмите «Кадр». Запись своего JPEG на Android 10+ не требует доступа ко всей галерее.

«Без статистики» здесь означает отключение найденных каналов аналитики и статистики мода. TikTok продолжает получать запросы, необходимые для входа, просмотра и общения. Полный аудит всех нативных каналов не выполнен.

## Повторная сборка

Нужны Python с `pyelftools`, JDK 17+, Android SDK build-tools 36.1.0 и `android-36.1/android.jar`, JADX 1.5.6, исходный APK с закреплённым SHA-256 и локальный ключ. `JAVA_HOME` должен указывать на JDK. В текущем подготовленном каталоге:

```powershell
python scripts/build_you_privacy.py
```

Для восстановления Java-инструментов из исходников:

```powershell
& "$env:JAVA_HOME/bin/javac.exe" -cp "tools/jadx/lib/jadx-1.5.6-all.jar" -d tools scripts/DexTool.java scripts/SourceTool.java
```

Сборщик заново извлекает исходные классы, обновляет инвентаризацию запросов разрешений, создаёт отдельный каталог патчей, проверяет контрольные инструкции нативной части, наборы классов, хеш встроенного payload, подпись и выравнивание. Старые патчи 47.1.4 не используются.

Исходники новых функций — `src/mod/privacy`; версионные патчи — `scripts/build_you_privacy.py`, `scripts/you_manifest.py`, `scripts/you_native.py`. Проверки — `tests/PrivacyPolicyTest.java` и `tests/android/PrivacyProbeInstrumentation.java`. Инструментальный тест использует упрощённый Application; обычный запуск проверяется отдельно.

Ключ `tools/signing/local-clean.jks` и пароль исключены из Git. Их нужно сохранять для следующих выпусков и не публиковать. Сборку 2024608034 нужно один раз установить вручную поверх 2024608033: адрес технического канала изменился. Затем приложение проверяет новый выпуск при открытии, не чаще раза в час. В старой сборке источник также можно заменить долгим нажатием на строку обновлений: `https://raw.githubusercontent.com/topikajo/tiktok-clean/updates/update.json`. APK не содержит GitHub-токенов и не устанавливается без нажатия.

## GitHub Desktop и публикация

Локальный репозиторий подключён к GitHub Desktop из `C:\projects\tictok mod`, remote — `topikajo/tiktok-clean`. Все коммиты и изменения видны в Desktop. Исходные APK, инструменты, временные данные и ключи не попадают в Git; готовые APK находятся в Releases.

Последовательность проверок и публикации описана в [AGENTS.md](AGENTS.md). После сборки:

```powershell
python scripts/test_privacy_jvm.py
python scripts/run_privacy_stress.py fixed
python scripts/build_you_probe.py
python scripts/build_you_probe.py --stress
python scripts/build_you_probe.py --updates
# Установить готовый APK на собственный одноразовый TikTokAudit, emulator-5580.
python scripts/test_you_android.py
python scripts/verify_you_privacy.py
python scripts/smoke_you_startup.py
python scripts/prepare_public_release.py
# Проверить изменения, Commit и Push origin в Desktop.
python scripts/publish_github_release.py
```

Публикация создаёт отдельный технический prerelease для JSON и отчётов, проверяет размеры и SHA-256, затем публикует обычный выпуск только с APK. После проверки публичного скачивания отдельный технический push обновляет ветку `updates`; она содержит адрес и хеш новой сборки и не меняет рабочую папку в Desktop. JSON ссылается на неизменяемый адрес APK конкретного тега. [Отчёт нагрузки](release/stress-results.json) показывает границы и результаты измерений.
