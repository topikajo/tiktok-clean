# ARM7 / 32 бит

`ttc-arm7.apk` и `ttc-arm32.apk` — одинаковая отдельная сборка с настоящими библиотеками `armeabi-v7a`, Android 6+. ARM8/ARM64 — другая сборка. Не устанавливайте все четыре файла.

Основа ARM32 — оригинальный TikTok 47.1.4 через сохранённый Clean Universal этого проекта. Все 293 нативные библиотеки ARMv7 совпадают побайтно с официальной основой; 265 имеют заголовок ELF32 ARM, остальные — упакованные исходные библиотеки. Чужие архитектуры удалены. You 4.4 остаётся только основой ARM64.

В ARM32 сохранены прежние фильтры рекламных роликов и экспериментальные функции чатов. Отключены найденные Java-каналы AppLog/AppsFlyer, получение рекламного ID и узкий список адресов аналитики. Камера, микрофон, контакты и уведомления запрашиваются через проверку действия пользователя. Автоогонёк по умолчанию выключен; периодическая задача появляется только после включения хотя бы для одного чата. Скачивание и качество из You, сохранение кадра и прошлого ролика сюда не перенесены. Серверные ограничения TikTok остаются.

Обновления находятся во «Входящих» и в настройках. ARM32 использует отдельный канал `https://raw.githubusercontent.com/topikajo/tiktok-clean/updates/update-arm32.json`; APK другой архитектуры отклоняется дополнительно к проверке подписи, пакета, версии и SHA-256. Для установки нажмите кнопку самостоятельно. Внутри APK нет GitHub-токена.

Статус: **экспериментальная**, физический ARMv7-телефон не проверен. 61 проверка установленного APK прошла в настоящем 32-битном процессе Android 11 с изолированным Application: разрешения, подпись и неверные обновления, интерфейс строки обновлений, привязки Google/email и модели чатов. Дополнительно прошли 100 000 обращений к настоящей модели видео через кэшированный вызов. Это не проверка реального входа, переписки, видеодекодера, живой ленты или FPS.

Обычный запуск на Android 11 x86 с ARM-транслятором падает в `libndk_translation.so`: `Bad ubidi_openSized_66 call`. Нетронутый официальный APK в том же ARMv7-режиме падает так же. Причина этой ошибки относится к среде проверки; из неё нельзя сделать вывод об успешном запуске на телефоне. Другие попытки и окончательный статус записаны в [release/arm32-startup.json](release/arm32-startup.json).

Проверяемые отчёты: [сборка](release/arm32-build.json), [установленный APK](release/arm32-android-checks.json). Сборщик требует оба закреплённых входных APK, JDK, Android SDK, JADX/DexTool и локальный ключ. Эти большие бинарные зависимости и ключ не публикуются в Git. Это сборка из сохранённой бинарной основы, а не сборка TikTok из исходников.

```powershell
python scripts/build_arm32_clean.py
python scripts/build_arm32_probe.py
python scripts/test_arm32_android.py
python scripts/prepare_arm32_release.py
# Проверить и закоммитить исходники/отчёты, Push main.
python scripts/publish_arm32_release.py
```

Переход между ARM32 и ARM64 может потребовать удаления из-за независимых versionCode. Перед удалением сохраните локальные черновики. Сертификаты Android удалять не нужно.
